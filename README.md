# LPI · Manejo de Archivos PT2

Repositorio académico enfocado en el uso de **archivos en C++**, correspondiente a prácticas de Lenguajes de Programación.

## Descripción

Este repositorio reúne ejercicios relacionados con lectura, escritura y manipulación de archivos, aplicando conceptos básicos de persistencia de datos en programas de consola.

## Temas trabajados

- Manejo de archivos con C++.
- Lectura y escritura de datos.
- Uso de `fstream`, `ifstream` y `ofstream`.
- Organización de información en archivos de texto.
- Prácticas de persistencia básica.

## Objetivo académico

Comprender cómo los programas pueden almacenar y recuperar información desde archivos externos, fortaleciendo la lógica de programación y la gestión de datos.
